# STM32 Embedded Development

A hands-on learning journey into embedded systems development using the STM32 microcontroller family.

This repository contains a series of projects developed to explore microcontroller architecture, low-level programming, and embedded software development.

## Hardware

- STM32F407G-DISC1 Discovery board

## Projects

| # | Project | Concepts |
|---|---------|----------|
| 01 | LED GPIO | GPIO configuration, registers, clock enable |

## Learning Goals

- Understand microcontroller architecture and memory-mapped registers.
- Develop a solid foundation in C and low-level programming.
- Explore interrupts, timers, communication peripherals, and other MCU features.
- Progress toward more advanced embedded systems development.
